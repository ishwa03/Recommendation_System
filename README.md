#  Movie Recommendation System

This project is a **Movie Recommendation System** that recommends similar movies using a **mixed approach**. It combines **content-based filtering** (cosine similarity) and **clustering techniques** (KMeans) to suggest movies based on similarity scores.

---

##  Features

-  Content-based recommendations using **Cosine Similarity**
-  Clustering of movies using **KMeans**
-  Stemming applied to movie titles for better matching
-  Shows top 5 most similar movies
-  User-friendly web interface built with **Flask**

---

##  Technologies Used

- Python
- Pandas, NumPy
- Scikit-learn
- Flask
- Pickle (for saving data)
- PyCharm (for development)

## 🚀 How to Run the Project

### 1. Clone the repository:

git clone https://github.com/ishwa03/Recommendation_System.git
cd Recommendation_System   

2. Create a virtual environment
   python -m venv venv
source venv/bin/activate  # For Windows: venv\Scripts\activate



4. Install the dependencies:
